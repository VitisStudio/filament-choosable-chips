# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

Security fixes are released for the latest minor release of the current major version.

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues,
discussions, or pull requests.

Instead, report them privately using either:

- GitHub's [private vulnerability reporting](https://github.com/vitisstudio/filament-choosable-chips/security/advisories/new), or
- email to **dan@vitis.studio**.

Where possible, please include:

- a description of the vulnerability and its impact,
- the affected package version, along with the PHP, Laravel, and Filament versions,
- steps to reproduce, or a proof of concept.

You will receive an acknowledgement of your report. Once the issue is confirmed, a
fix will be released, and you will be credited in the advisory and the changelog
unless you ask to remain anonymous.

## Scope

This policy covers the `vitisstudio/filament-choosable-chips` package only.
Vulnerabilities in Filament or Laravel themselves should be reported to their
respective maintainers.
